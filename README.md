# 相場の自動取得（個人用）

国土交通省「不動産情報ライブラリ」のAPIで、東京都（島しょ部を除く）と近接市の**取引価格・成約価格**を集計する個人用のスクリプトです。
GitHub Actions が毎週土曜の早朝（日本時間）に動き、国交省が新しい四半期を公表したときだけ `data/` の集計を作り直します（それ以外の週は確認だけ）。

| ファイル | 中身 |
|---|---|
| `data/status.json` | 最後に確かめた日時・公表済みの最新の四半期・成否 |
| `data/souba_reinfolib_latest.json` | 市区町村 × 種別 × 築年帯の㎡単価（直近2年） |
| `data/souba_reinfolib_hist_latest.json` | 23区の築年をそろえた㎡単価の推移（2006年〜） |

- 手で動かすとき：Actions → souba-auto → Run workflow（「新しい四半期が無くても全部取り直す」にチェックを入れると全部取り直す。25分ほど）
- 失敗すると GitHub から通知メールが届きます。理由は `data/status.json` の `error` と、Actions の実行ログに出ます

## APIキー
キーはこのリポジトリのどのファイルにも入っていません。**Settings → Secrets and variables → Actions の `REINFOLIB_API_KEY` にだけ**置きます。
スクリプトはキーを画面にもファイルにも書き出しません。

## 出典
このサービスは、国土交通省の不動産情報ライブラリのAPI機能を使用していますが、提供情報の最新性、正確性、完全性等が保証されたものではありません。
